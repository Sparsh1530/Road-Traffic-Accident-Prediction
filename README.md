# Road Traffic Accident Prediction Using Machine Learning

## Project Overview
This project aims to predict road traffic accidents and identify accident-prone zones using Machine Learning techniques. The model analyzes historical accident records along with weather and environmental factors to estimate accident risk.

## Objectives
- Analyze historical accident data.
- Identify factors contributing to accidents.
- Predict accident-prone areas.
- Support data-driven road safety decisions.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Jupyter Notebook

## Dataset
UK Road Safety Dataset

## Features
- Data Cleaning and Preprocessing
- Exploratory Data Analysis (EDA)
- Feature Engineering
- Machine Learning Model Training
- Model Evaluation
